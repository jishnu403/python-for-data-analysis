1.Project Title: Social Media Engagement Analytics Using Python
.Main Goal: To analyze, clean, visualize, and perform statistical operations on a social media dataset (5,000 rows) using Python.
.Main Tasks & Steps:
2.Data Import & Setup: Loaded the CSV file using Pandas and checked the data types.

3.Data Cleaning: Handled missing values , removed duplicates, corrected invalid values, and formatted text data.

4.Data Exploration: Gathered basic insights using describe, , correlation matrices, and group-by operations.

5.Data Wrangling: Created new derived columns such as engagement score, log-transformed metrics, and hashtag counts.

6.Statistical Analysis: Calculated key statistical metrics including mean, median, mode, variance, standard deviation, and percentiles.

7.Data Visualization: Generated various plots using Matplotlib, Seaborn, and Plotly 
e.g, Scatter, Line, Bar, Pie, Histogram, Box plot, Count plot, Violin plot, Heatmap, Swarm plot.

Tools;

.Pandas: Used for loading the dataset (CSV), cleaning data, dataframe manipulations, groupby operations, and generating summary statistics.

.NumPy: Used for basic mathematical and array operations (working alongside Pandas).

.Matplotlib: Used for creating basic charts and plots (e.g., Scatter, Line, Bar, Pie, Histogram, and Box plots).

.Seaborn: Used for advanced and attractive statistical data visualizations (e.g., Count plots, Bar plots, Violin plots, Pair plots, Heatmaps, and Swarm plots).
